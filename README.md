# 日本 航空気象ダッシュボード（METAR / TAF）

日本全国の空港の **METAR（気象実況）** と **TAF（気象予報）** を常時表示する、単一HTMLファイルのWebダッシュボードです。ブラウザで `index.html` を開くだけで動作し、サーバーは不要です。

![status](https://img.shields.io/badge/type-static%20HTML-blue) ![data](https://img.shields.io/badge/data-NOAA%20aviationweather.gov-green)

## 主な機能

- 日本全国 **94地点** をリクエスト対象とし、配信中の空港（民間空港・米軍基地・軍民共用空港）を表示
- 各空港カードに表示する情報:
  - 飛行カテゴリバッジ（VFR / MVFR / IFR / LIFR を色分け）
  - 風向風速・視程・気温/露点・気圧・雲
  - 生の METAR / TAF 電文
- **エリア別フィルタ**: 北海道 / 東北 / 関東 / 中部 / 関西 / 中国 / 四国 / 九州 / 沖縄
- **検索**: ICAOコード・英語名・日本語名（例:「羽田」「基地」）に対応
- **並び替え**: 悪天候順（LIFR→VFR）/ ICAOコード順 / 空港名順
- **1分ごとの自動更新**（手動更新ボタン・次回更新までのカウントダウン付き）
- `localStorage` によるキャッシュ（取得失敗時は前回データを表示し続ける）

## データソース

- **[NOAA aviationweather.gov Data API](https://aviationweather.gov/data/api)**（無料・APIキー不要）
- ブラウザから直接アクセスできない（CORS非対応）ため、公開CORSプロキシを経由しています。
  安定性のため **corsproxy.io → allorigins.win → codetabs.com** の順で自動フォールバックします。
- 一括取得（94地点分）が失敗した場合は、15地点ずつに分割して再試行します。

## 自衛隊基地について

純粋な自衛隊基地（千歳・厚木・下総・入間・浜松・築城・新田原・鹿屋など19基地）は、
**2011年10月以降 METAR/TAF を国際気象配信網（GTS）へ流していないため、原則として表示されません。**
ただし稀に配信されることがあるため（下総は2026年も散発配信を確認）、リクエスト対象には含めており、
データが流れた時のみ「自衛隊」バッジ付きのカードが自動表示されます。

米軍基地（横田・嘉手納・普天間）と軍民共用空港（三沢・岩国・百里・小松・美保・徳島など）は常時表示対象です。

## 使い方

`index.html` をブラウザで開くだけです。

ローカルサーバーで動かす場合の例:

```bash
python -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## 既知の制約

- 無料の公開CORSプロキシに依存しているため、プロキシが停止・制限された場合はデータ更新が止まります（キャッシュ済みデータの表示は継続）。
- METAR は通常1時間ごとの発表です。1分ごとに取得しても内容が変わるのは主に急変時の SPECI（臨時報）発表時です。
- TAF は全空港では発表されていません（約43地点）。
